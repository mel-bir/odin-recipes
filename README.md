# Odin Recipes

A foundational HTML project showcasing a collection of favorite recipes. This project demonstrates the ability to structure a multi-page website using semantic HTML, create internal navigation links, and present content in a clean, organized manner.

## Skills Demonstrated

- Creating a well-structured HTML document with proper boilerplate
- Building a multi-page website with internal navigation links
- Organizing content using headings (`<h1>`), paragraphs (`<p>`), and lists (`<ul>`, `<ol>`)
- Embedding images (`<img>`) with appropriate attributes
- Linking between pages using relative paths (`<a href="...">`)
- Structuring recipe content for readability and user experience

## Recipes Included

- **Cold Brew Mocha Freeze** – A decadent frozen coffee treat blending smooth cold brew concentrate with rich chocolate, milk, and ice, topped with whipped cream.
- **Provolone Sandwich** – A simple, savory sandwich highlighting creamy provolone cheese on crusty bread with classic Italian fixings.
- **Rotisserie Chicken Chef Salad** – A hearty, protein-packed salad with rotisserie chicken, bacon, hard-boiled egg, and fresh vegetables.
- **Strawberry Banana Smoothie** – A classic, creamy smoothie made with frozen fruit, yogurt, and milk – ready in just five minutes.

---

## How to View

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Click on any recipe link to navigate to the detailed recipe page.
4. Use the **Home** link on each recipe page to return to the main index.
